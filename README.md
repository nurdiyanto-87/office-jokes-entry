A single one-line joke about office life — a performance review with a twist — written to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty, $5 in USDC. The joke turns the review ritual inside out: told he excels at meetings but not at actual work, the speaker books more meetings.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (set `ENTRY_OUTPUT` to write it elsewhere for local testing).
